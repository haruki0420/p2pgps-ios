# Setup iPad

iPad の準備（Developer Mode / LocalDevVPN / pairing file / DDI）は、プロジェクト全体の Wiki にまとめています。

- [Setup iPad（全体版）](https://github.com/haruki0420/p2pgps/wiki/Setup-iPad)

このアプリ固有の点:

- アプリの入手: [Releases](https://github.com/haruki0420/p2pgps-ios/releases) の未署名 IPA を SideStore / AltStore で入れる
- 設定画面で pairing file を読み込み、DDI をダウンロードして使える状態にする
- 「位置情報を反映」を ON にする

困ったときは [Troubleshooting](Troubleshooting) を見てください。
