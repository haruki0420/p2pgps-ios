# よくある質問

## Mac が無くても使えますか？

はい。ビルドは Linux / WSL2 + xtool で行えます。iPad の初回準備には Windows / macOS / Linux のパソコンが必要です。

## iPad の位置を元に戻すには？

Receiver 画面で「位置情報を反映」を OFF にするか、送信側で停止します。

## 位置情報はどこかに送られますか？

送られません。スマートフォンと iPad の間の Bluetooth だけでやり取りします。

## iPhone と Android のどちらでも使えますか？

どちらでも使えます。iPad 側のアプリは同じです。

## 位置の更新間隔は変えられますか？

設定画面から 0.1〜5 秒の範囲で変更できます（既定 1 秒）。

## バッテリーはどれくらい減りますか？

Bluetooth と位置情報を使うため、連続使用で 1 時間あたり数 %〜10 % 程度と想定しています（実測未実施）。間隔を長くすると節約できます。

## アプリを再起動すると位置が戻りません

前回の位置変更が iPad 側に残っている可能性があります。iPad を再起動するか、「位置情報を反映」を ON → OFF してください。

## うまくいかないときは？

[困ったとき](Troubleshooting) を見てください。技術的なログは「困ったとき」画面の「動作記録」にあります。
